# Gathering Presentation Source Models

Held, presentation-only source models for future gathering/resource-node presentation.

This pack provides four reusable silhouettes—mineral outcrop, salvage pile, herb cluster, and fallen timber—without claiming that any model is a canonical gatherable resource. BA-023 gathering contracts remain dormant, and BA-025 validates caller-supplied cross-domain reference registries but does not publish live resource, tool, respawn-policy, or reward IDs.

Accordingly, this pack has no canonical gameplay bindings. Its `presentationId` and `modelPath` values identify visual source assets only. `GroundSnap`, `GatherVfx`, and `GatherAudio` attachments are presentation sockets; they do not create prompts, interactions, harvesting, depletion, rewards, respawns, networking, persistence, or Main World activation.

All source parts are anchored and the models contain no scripts or remotes. They remain runtime-unmapped and Studio-unapproved until a later integration pass can bind them to explicitly authored canonical content and accepted Studio evidence.
