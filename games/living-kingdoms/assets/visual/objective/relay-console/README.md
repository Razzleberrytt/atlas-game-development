# Relay Console Procedural Fallback

This VIS-0105 package provides a project-original client-local relay-console shell around the unchanged server-authored `ConsoleBody` and `StatusLamp`.

## Readable states

- `RELAY STANDBY` appears only for the authoritative insertion/inactive snapshot.
- `RESTORE RELAY` appears only for the authoritative infiltration/active snapshot.
- `RELAY ONLINE` appears only after the objective is authoritatively completed.
- malformed or inconsistent facts restore the primitive server presentation instead of fabricating a state.

The fallback uses eleven non-collidable presentation parts: plinth, side shells, front panel, top housing, screen, status lens, two antennae, cable box, and screen guard. Geometry and text carry meaning; color is supplemental.

## Authority boundary

The client never moves or resizes the server body, changes collision, enables or triggers the prompt, completes the objective, changes phase, or publishes mission state. It only hides the primitive body/lamp locally while a validated visible state is rendered.

## Remaining gates

Roblox Studio gameplay-camera, prompt readability, lighting interaction, final materials, authored effects/audio, and representative performance approval remain pending.
