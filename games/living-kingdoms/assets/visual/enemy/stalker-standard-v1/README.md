# Stalker Standard V1

Held, presentation-only source blockout for `enemy.presentation.stalker.standard_v1`.

## Visual identity

The baseline Stalker should still feel wrong rather than generic: broken joint angles, a rib-cage silhouette that reads through the torso, a head cocked into a searching posture, and a small sensor weak point that can flare during attack tells. It is the restrained horror baseline against which the more extreme horde roles stand out.

## Iteration boundary

A final mesh/rig may replace this blockout, but should preserve the wrong-joint-angle body language, readable rib structure, searching-head posture, sensor focus, and attack tells. This source owns no AI, damage, spawning, rewards, targeting, or role assignment and remains unmapped until a later integration pass.
