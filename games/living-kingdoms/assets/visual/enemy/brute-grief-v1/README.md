# Brute Grief V1

Held, presentation-only source blockout for `enemy.presentation.brute.grief_v1`.

## Visual identity

The Brute should read as a heavy industrial nightmare before texture detail is visible: a forward-hunched torso mass, one grotesquely overgrown arm, embedded plate/rebar debris, and a bright back-growth weak point. The right side intentionally carries much more mass so its threat direction and attack wind-up remain readable.

## Iteration boundary

A final mesh/rig may replace this primitive blockout, but should preserve the one-arm overgrowth, embedded-industrial-debris language, forward-hunched mass, readable back-growth focus, and attack tells. This source owns no AI, health, damage, stagger, spawning, rewards, or navigation behavior and remains unmapped until a later integration pass.
