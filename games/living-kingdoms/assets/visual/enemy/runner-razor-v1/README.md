# Runner Razor V1

Held, presentation-only source blockout for `enemy.presentation.runner.razor_v1`.

## Visual identity

The Runner should read as a speed threat before animation detail exists: a blade-thin torso pitched forward, a head projecting ahead of the chest, overlong forearms, and low cutting claws. The shape is intentionally narrow and directional so players can identify a sprinting threat in peripheral vision.

## Iteration boundary

A final mesh/rig may replace this blockout, but should preserve the overlong forearms, blade-thin torso, head-forward sprint posture, readable chest weak-point focus, and attack tells. This source owns no speed, AI, damage, navigation, spawning, rewards, or role assignment and remains unmapped until a later integration pass.
