# Screamer Choir V1

Held, presentation-only source blockout for `enemy.presentation.screamer.choir_v1`.

## Visual identity

The Choir should read as a tall signaling threat before detail is visible: an unnaturally elongated neck, a three-pronged split throat array, and a lantern-like rib cavity. The throat array is the presentation weak-point focus and also carries audio/VFX origins so later art and animation can make the scream visibly charge before release.

## Iteration boundary

This primitive source model is intentionally replaceable by a final mesh/rig. Preserve the registry identity, tall-beacon silhouette, elongated-neck/split-throat/lantern-rib language, and readable attack tells when replacing it. It owns no AI, damage, spawning, rewards, or scream mechanics and remains unmapped until a later integration pass.
