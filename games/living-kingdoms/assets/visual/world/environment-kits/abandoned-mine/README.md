# Abandoned Mine Environment Kit v1

Held source-model inventory for the Living Kingdoms dark-frontier / abandoned-industry environment language.

This kit is intentionally **not mapped into `main-world.project.json`**. It may be reviewed, expanded, or replaced without changing gameplay authority or Claude-owned BA-014 Main World acceptance/mapping work.

## v1 modules

- `MineSupportA.model.json` — repeatable 16×16×8 tunnel support frame with semantic snap and lantern sockets.
- `BrokenSupportA.model.json` — damaged structural variant for collapse/storytelling language.
- `OreCartA.model.json` — reusable industrial storytelling prop.
- `TimberBarricadeA.model.json` — modular blocked-route/dressing prop.

All geometry is project-original source-safe blockout geometry. It is **source prepared**, not Studio-approved final art. Final authored meshes/materials may replace these blockouts while retaining stable semantic IDs and required sockets.

## Boundaries

- no scripts, remotes, prompts, AI, loot, gathering, crafting, or quest authority;
- no runtime mapping or activation;
- all Parts are anchored source geometry;
- gameplay collision semantics remain registry metadata until a later placement/integration pass;
- asset validation must keep the manifest, environment registry, source files, and MineSupportA sockets aligned.
