# Abandoned Interior Props

Held, presentation-only dressing for ruined frontier and abandoned-industry interiors.

The kit provides a broken table, rusted locker, cot frame, and wall shelf so modular structures can read as previously occupied spaces instead of empty shells. Prop sockets are presentation hooks only; they do not imply loot, storage, interaction, crafting, or persistence authority.

All source models remain runtime-unmapped and Studio-unapproved until a later placement/integration pass.
