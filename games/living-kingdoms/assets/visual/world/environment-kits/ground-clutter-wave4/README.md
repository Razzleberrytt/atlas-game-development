# Ground clutter wave 4

Held, project-original ground-detail source models for future Living Kingdoms environment composition.

This pack deliberately stays small, non-colliding, presentation-only, runtime-unmapped, and Studio-unapproved. It increases future scene-density options without deciding BA-014 streaming density, placement frequency, quality-tier culling, or performance budgets before measurement.

Included source models:
- `DryBrushPatchA` — reusable dead frontier brush.
- `StoneShardScatterA` — low-profile rock fragments for frontier/mine transitions.
- `RustedScrapScatterA` — industrial debris detail for abandoned industry and mine spaces.
- `CorruptionTendrilMatA` — corruption floor tendrils with one VFX presentation socket.

`EnvironmentAssetKitRegistryWave4` owns stable semantic IDs and presentation metadata. These files own no hazards, gathering, loot, damage, navigation, corruption state, persistence, or interaction behavior. Every Part is anchored and the pack contains no scripts or remotes.
