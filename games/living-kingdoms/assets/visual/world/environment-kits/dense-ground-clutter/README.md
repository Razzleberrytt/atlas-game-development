# Dense Ground Clutter Environment Kit

Held, presentation-only source models for repeatable low-silhouette ground dressing across frontier, mine, industrial, and corrupted spaces.

`PebbleScatterA`, `FallenBranchTangleA`, `CaveShardScatterA`, and `DeadBrushMatA` are designed for dense repetition without changing route readability. Final meshes may replace the primitive geometry without changing semantic IDs.

These assets are not resource nodes and own no harvesting, loot, rewards, depletion, respawn, traversal, hazards, AI, interaction, or progression. They remain runtime-unmapped and Studio-unapproved until a later integration pass.
