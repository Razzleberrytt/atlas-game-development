# Natural Variation Wave 7

Held, presentation-only natural variants for wilderness repetition control.

This pack adds a second dead-pine silhouette, boulder cluster, twisted corrupted root, and brush snag. The goal is to reduce obvious copy-paste repetition while preserving the same biome language and environment-authority boundaries.

These assets own no gathering, collision gameplay, hazards, navigation, loot, or progression and remain runtime-unmapped and Studio-unapproved.
