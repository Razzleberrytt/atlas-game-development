## Durable merge rule

`games/living-kingdoms/src/` is the only gameplay-authoritative source tree. Imported Studio content is preservation/reconciliation input, never a parallel runtime authority.

When old and new systems overlap, keep the canonical modern owner and port only missing content, data, rules, or presentation through that owner. Do not solve overlap by running both systems.

Historical merge counts, completed PR numbers, reconstruction batches, and superseded next-step lists are available in Git history and migration evidence rather than duplicated here.
