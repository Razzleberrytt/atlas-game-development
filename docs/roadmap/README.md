# Living Kingdoms Roadmap Index

Use the roadmap documents in this order:

1. [`MASTER-ROADMAP.md`](MASTER-ROADMAP.md) — completed milestone history, preserved foundation work, and high-level P0–P12 sequence.
2. [`P6-P12-EXECUTION-ROADMAP.md`](P6-P12-EXECUTION-ROADMAP.md) — current status and the canonical PR-sized process for completing every remaining MVP task.

When the two documents differ in detail for unfinished P6–P12 work, the execution roadmap controls task IDs, dependencies, acceptance gates, execution order, and current status. The master roadmap continues to control completed history and the overall milestone order.

Specifications define the behavior inside a roadmap task. The active specifications are linked from the execution roadmap, including:

- [`../specifications/ammunition-scarcity-and-supply.md`](../specifications/ammunition-scarcity-and-supply.md) for the remaining P6 evidence and tuning process;
- [`../specifications/mvp-specialist-classes.md`](../specifications/mvp-specialist-classes.md) for the completed P7 plan and upcoming class implementation.

A task moves to complete only after its applicable Definition of Done, automated validation, required Studio evidence, documentation, and status update are all satisfied.
