# Live Expedition Lobby Integration

The lobby now replaces the Studio-only expedition start path for ordinary players.

- Client requests are limited to join, leave, and ready state for the invoking player.
- Membership, readiness, capacity, launch freezing, and launch consumption are server-owned.
- The lobby supplies only party size to the live expedition runtime.
- Expedition seed and run ID remain server-generated.
- Studio execution evidence is still required before the integration is considered validated.
