# Blueprint v2.7 Runtime Evidence Packet Template

Use one copy of this template for every Studio/runtime run that is used to close a v2.7 gate or promote an evidence level.

Suggested location:

```text
docs/production/evidence/YYYY-MM-DD-<ticket>-<short-name>.md
```

A packet records what actually happened. Do not edit an old packet to make a later run look cleaner; create a new packet and link the superseded one.

## 2. Claim under test

State one falsifiable claim.

Example:

```text
After enabling ready-gated semantic delivery, a deliberately delayed client reaches ClientReady,
receives the current route/objective state exactly once per semantic key, and produces zero
HordeNetwork.State queue/discard warnings.
```

Do not use vague claims such as “networking looks fixed.”
