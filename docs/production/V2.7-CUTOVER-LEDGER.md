## Compatibility removal checklist per row

A state or presentation compatibility row is removable only when all are true:

- [ ] Replacement path is active.
- [ ] Replacement evidence packet is accepted.
- [ ] Required current state survives delayed ready / late join where applicable.
- [ ] Old path receives no required traffic.
- [ ] No other unmigrated row depends on the old path.
- [ ] Reset/respawn cleanup remains within accepted baseline.
- [ ] One rollback checkpoint remains available.
- [ ] Removal PR updates this ledger.
